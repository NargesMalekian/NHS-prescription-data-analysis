# NHS-prescription-data-analysis
SQL-based analysis of NHS prescription data, including cost analysis, trend detection, and anomaly identification using advanced SQL.


This project demonstrates SQL-based analysis on NHS prescription data.

## Key Analyses
- Identified most prescribed drugs per month using window functions (DENSE_RANK)
- Analyzed prescription cost distribution (min, avg, max) by BNF category
- Detected unusual high-cost prescriptions and potential anomalies
- Performed month-over-month cost trend analysis using LAG()
- Derived insights for bulk purchasing and healthcare decision-making

## Skills
- SQL (T-SQL)
- Data Analysis
- Window Functions (RANK, LAG, DENSE_RANK)

## Notes
This repository contains selected queries only. Full dataset is not included.
